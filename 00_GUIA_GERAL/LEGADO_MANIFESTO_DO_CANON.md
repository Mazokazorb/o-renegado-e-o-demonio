# Manifesto do Canon

Este projeto deve preservar:
- mistério quando o autor escolheu mistério;
- causalidade quando estabelecida;
- personagens sem motivações inventadas;
- músicas como referência cultural;
- perguntas antes de preencher lacunas relevantes;
- separação rígida entre canon e ideias;
- ausência de conteúdo inventado para o segundo arco.
